# Rules for any Claude session working in this repo

The daily briefing posts to the #robotics-daily-briefing Slack channel automatically every weekday morning. That is the only post that may happen without Isabel. Leave it running and do not change how it works.

Anything else that would put a message in Slack needs Isabel's explicit OK in the conversation first. That includes:
- Creating, editing, or deleting any file in the briefings/ folder
- Running, re-running, or manually starting any GitHub workflow that posts to Slack (Daily Briefing, Post Social Content to Slack, Publish Zenie Drafts from Email, or any other)
- Turning a disabled workflow back on, especially Post Briefing to Slack
- Adding a new workflow or script that posts to Slack

If you are unsure whether a change could cause a Slack post, assume it can and ask Isabel first.
