# ART Lab Instagram drafts

Working folder for the ART Lab Instagram agent (the art-lab-instagram skill and its weekly scheduled task).

- `tools/render_carousel.py` renders a typographic carousel spec to 1080x1350 PNGs.
- `tools/render_reel.py` renders the same spec as a silent 1080x1920 reel with motion in the first frame.
- `drafts/<date>/<post>/` holds each post: slides or reel, caption.txt (caption, alt text, hypothesis, originality, sources) and spec.json.

Nothing in this folder posts anywhere. No workflow watches it. Isabel uploads approved posts to Planable herself.
